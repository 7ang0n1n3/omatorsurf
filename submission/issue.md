### Maintainer notes

Omatorsurf provides Tor routing controls and observed protection status. Plugin version 1.0.2; backend version 1.0.0. Please review for manual installation: the native Rust backend, Tor/nftables dependencies and root-owned status publisher require the documented installer. Start/Stop/NEWNYM use pkexec; installation updates the bar layout with backups and does not enable Tor routing. Plugin-only removal preserves backend routing; full removal restores direct networking. See SECURITY.md and submission/VALIDATION.md for capabilities and testing limits. Privileged widget interactions remain untested. No preview asset is included.
